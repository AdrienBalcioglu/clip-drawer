# Clip Drawer

A drawer for the bits of text you paste again and again. Click to copy.

**[Website](https://adrienbalcioglu.github.io/clip-drawer/about.html)** · **[Open the app](https://adrienbalcioglu.github.io/clip-drawer/)**

## Features

- Click a clip, or press Enter on it, to copy it
- Tags and instant search (press `/`)
- Most used clips come first
- Export and import as JSON

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Everything is saved in the browser's local storage. No account, no API key, no server: nothing leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
